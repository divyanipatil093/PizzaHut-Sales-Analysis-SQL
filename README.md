# 🍕 Pizza Hut Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes Pizza Hut sales data using SQL queries to uncover business insights such as:

- Revenue generation
- Customer ordering behavior
- Top-selling pizzas
- Peak sales hours
- Pizza category performance

The project demonstrates practical SQL skills used in real-world business analytics.

---

## 🛠 Tools & Technologies Used

- MySQL
- SQL
- Microsoft PowerPoint
- GitHub

---

## 📂 Dataset Tables

The analysis was performed using the following tables:

- orders
- order_details
- pizzas
- pizza_types

---

## 📊 Key Business Questions Solved

1. Retrieve total number of orders
2. Calculate total revenue
3. Identify highest-priced pizza
4. Find most common pizza size ordered
5. Determine top-selling pizzas
6. Analyze revenue contribution
7. Identify peak order hours
8. Generate cumulative revenue analysis

---

## 📈 Key Insights

- Large pizzas were ordered most frequently
- Evening hours generated maximum orders
- Chicken category generated highest revenue
- Revenue increased steadily over time
